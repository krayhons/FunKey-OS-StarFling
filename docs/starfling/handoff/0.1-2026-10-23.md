## Decisions made this chat (and why)

- **Build in a new `Ubuntu-22.04` distro rather than on 26.04** (K). Buildroot
  2021.02 host packages and `python3-distutils` don't work on 26.04's
  GCC 15 / Python 3.14. This keeps D5 as written.
- **Handled the 429 by prefetching sources, not changing code.** It was a
  transient GitHub rate limit, not a build break; `sources.buildroot.net` has
  no mirror of `v1.0-rg-nano.tar.gz`, so there is no fallback.
