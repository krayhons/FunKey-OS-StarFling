## Decisions made this chat (and why)

- **Runtime switch, not a debug build.** Instrumentation is on while
  `/mnt/starfling-boot/` exists. The same image is used for timing and
  production, K toggles it from Explorer, and logs return over MOUNT USB.
  Checked on the device: without the folder there are no marks and no
  collector, and `printk_devkmsg` keeps its default.
- **Marks in the kernel log instead of `/run/bootmarks`.** This gives µs
  timestamps on the kernel clock and one merged timeline, against 10 ms
  steps from `/proc/uptime`. It needs `printk_devkmsg=on` (set by rcS only
  when on); the default rate limit drops marks after 10 per 5 s.
- **Sourced function, one mark per script start.** A fork+exec is ~4.5 ms;
  start and end marks per script would double the cost for no extra
  information.
- **RetroFE marks also go to kmsg** (fd opened with `O_CLOEXEC`, so
  emulators do not inherit it). RetroFE's own log is copied by the
  collector rather than moved to `/mnt`, because an open file on `/mnt`
  blocks MOUNT USB (see the comment in `frontend`).
- **Collector waits 30 s, at nice 19**, so it does not overlap the boot it
  measures, and the notification tells K when it is safe to power off.
- **Bootchart via `bootchartd start` in rcS, not `init=` on the cmdline**, so
  the U-Boot environment stays untouched. It misses sysinit (the kernel log
  covers that).
